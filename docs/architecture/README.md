# Architecture diagrams

Mermaid (`.mmd`) text diagrams. GitHub renders `.mmd` blocks inline; to view
locally, paste the file contents into the [Mermaid Live Editor](https://mermaid.live)
or use a Mermaid-capable markdown previewer.

## Diagrams

- `system-context.mmd` — users and external systems at a high level.
- `container.mmd` — Docker compose containers, ports, and volumes.
- `read-flow.mmd` — sequence for `GET /api/v1/alumni`.

When architecture changes, update the relevant diagram(s) per `AGENTS.md`.
